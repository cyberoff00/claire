# /assets — 美术素材放这里

游戏会自动尝试加载本文件夹里的 PNG。**没有的图会显示成"标注了文件名和尺寸的占位块"。**
设计师只需按下表的文件名和尺寸把真 PNG 丢进来，刷新页面就替换上了，**无需改任何代码。**

完整规范见 `../art-collaboration-spec.md`（含色板、Aseprite、试点验证流程）。

## 通用规则
- 格式：PNG-32（带透明通道；全景底图可不透明）
- 尺寸：**严格按下表的像素尺寸**，按 1x 原始尺寸导出，不要预先放大
- 风格：等距插画（就按你给的那张参考图的风格走，最适合你）；可锁一个色板保持统一
- 坐标系：全景世界 1024 × 560；装饰小物和玩家小人都在这个坐标系里摆放

## 资产清单（v1）
> **场景现在是一张等距全景插画**（参考你给的那张 Office/Severance 风格图），尺寸 1024×560。
> 整个办公室（主管讲台、你的工位、同事隔间、打印机、饮水机、茶水间门）都画进这一张图里——
> 包括**坐着的同事们**（他们是画在背景里的，不单独动）。只有"你"是单独的小人，会在地面上走动。
>
> 玩家小人 char-player 是会走动的精灵：**脚画在 32×48 画布最底部**，背景透明。
